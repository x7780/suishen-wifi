# ROI 机会评估技能

## 什么时候使用

每次提出投资方案时，**必须**使用此技能对方案打分，再提交给董事长。

## 评分公式

```
机会评分 = (预期收益率% × 100) ÷ (回报天数 × 风险系数)
```

**风险系数对照表：**

| 风险等级 | 系数 | 说明 |
|---------|------|------|
| 极低 | 0.5 | 几乎确定盈利，如短期套利 |
| 低 | 1 | 风险可控，历史胜率>70% |
| 中 | 2 | 有一定不确定性，胜率50-70% |
| 高 | 4 | 波动大，胜率<50% |
| 极高 | 8 | 接近赌博，不建议 |

## 评分解读

| 分数 | 评级 | 建议 |
|------|------|------|
| ≥ 2.0 | ⭐⭐⭐⭐⭐ 极优 | 强烈推荐 |
| 1.0~2.0 | ⭐⭐⭐⭐ 优秀 | 推荐 |
| 0.5~1.0 | ⭐⭐⭐ 良好 | 可以考虑 |
| 0.2~0.5 | ⭐⭐ 一般 | 谨慎 |
| < 0.2 | ⭐ 差 | 不建议 |

## 使用示例

**方案A**：投入200元，5天后预期收益10%，风险低
```
评分 = (10 × 100) ÷ (5 × 1) = 200
极优 ⭐⭐⭐⭐⭐ → 强烈推荐
```

**方案B**：投入200元，30天后预期收益20%，风险中
```
评分 = (20 × 100) ÷ (30 × 2) = 33.3
良好 ⭐⭐⭐ → 可以考虑
```

**方案C**：投入200元，7天后预期收益5%，风险极低
```
评分 = (5 × 100) ÷ (7 × 0.5) = 142.8
极优 ⭐⭐⭐⭐⭐ → 强烈推荐
```

## 多方案对比输出格式

```
📊 ROI 机会评估报告
━━━━━━━━━━━━━━━━━━
| 方案 | 投入 | 收益% | 天数 | 风险 | 评分 | 评级 |
|------|------|-------|------|------|------|------|
| A    | 200元 | 10%  | 5天  | 低   | 200  | ⭐⭐⭐⭐⭐ |
| B    | 200元 | 20%  | 30天 | 中   | 33.3 | ⭐⭐⭐ |
| C    | 200元 | 5%   | 7天  | 极低 | 142.8| ⭐⭐⭐⭐⭐ |
━━━━━━━━━━━━━━━━━━
🏆 推荐方案：A（评分最高）
💡 理由：回报快、风险低、资金周转效率最高
```

## 核心原则

- **回报速度优先**：同等收益率，天数越少越好
- **风险惩罚**：高风险方案评分大幅降低
- **小资金策略**：1000元启动资金，优先选评分≥1.0的方案
- **不强求投资**：没有评分≥0.5的方案时，建议不投，等待更好机会
